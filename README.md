## 📈 Metrik Keputusan

### Investment Decision Matrix

```
CONFIDENCE LEVEL:
🟢 HIGH (>70%)     → Full position size
🟡 MEDIUM (50-70%) → Half position size
🔴 LOW (<50%)      → Pass (no trade)

EDGE ASSESSMENT:
✅ Probability of Success: >55%
✅ Risk/Reward Ratio: >1.5:1
✅ Correlation Check: Diversified
✅ Macro Alignment: Supports thesis
✅ Benchmark Contribution: Positive

If ANY criterion fails → PASS (no trade)
```

## 🚀 Autonomous Trading Cycle (Every 15-60 minutes)

```
┌─────────────────────────────────────────────────────────────┐
│        AUTONOMOUS FUND MANAGER CYCLE                        │
└─────────────────────────────────────────────────────────────┘

1. 📊 PORTFOLIO STATE CHECK
   ├─ Fetch current USDT balance
   ├─ Get all holdings
   ├─ Calculate total portfolio value (USD)
   └─ Determine allocation percentage

2. 🌍 MACRO ANALYSIS
   ├─ Check economic indicators
   ├─ Assess global liquidity conditions
   ├─ Determine Risk On / Risk Off status
   ├─ Identify current market phase
   └─ Record macro conditions

3. 📈 CRYPTO MARKET ANALYSIS
   ├─ Fetch BTC, ETH, top 50 altcoins prices
   ├─ Analyze 24h momentum & volume
   ├─ Calculate Bitcoin dominance
   ├─ Check stablecoin liquidity
   ├─ Monitor capital flows
   ├─ Assess network activity (on-chain)
   └─ Evaluate market sentiment

4. 🧠 FUNDAMENTAL ANALYSIS
   ├─ Score each asset 1-100
   ├─ Evaluate: adoption, utility, revenue
   ├─ Check: security, institutional interest
   ├─ Assess: narrative strength
   └─ Rank by quality

5. 🎯 BENCHMARK COMPARISON
   ├─ Current performance vs IHSG
   ├─ Current performance vs S&P 500
   ├─ Current performance vs Gold
   ├─ Current performance vs Bitcoin
   ├─ Current performance vs Top 100 Crypto
   ├─ Determine which benchmarks you're beating
   └─ Identify underperformance areas

6. 💡 AI DECISION MAKING
   ├─ Analyze all factors above
   ├─ Generate BUY recommendations
   ├─ Generate SELL recommendations
   ├─ Generate HOLD recommendations
   ├─ Assign confidence levels
   ├─ Calculate position sizes
   ├─ Set stop-loss & take-profit levels
   └─ Create transaction plan

7. ✅ EXECUTION GATE
   IF probability > 55% AND risk/reward > 1.5 THEN
   ├─ Place BUY orders (with slippage protection)
   ├─ Place SELL orders (take-profit/stop-loss)
   ├─ Update portfolio allocation
   └─ Record all trade details
   ELSE
   └─ PASS (No trade - valid decision)

8. 📝 RECORD & UPDATE
   ├─ Save cycle details to history
   ├─ Calculate performance vs benchmarks
   ├─ Update dashboard with insights
   ├─ Log AI reasoning
   └─ Archive decision matrix

9. 🔄 REPEAT
   └─ Wait 15-60 minutes → Next cycle
```

## 🔧 Setup & Configuration

### Quick Start (60 Detik)

```bash
# 1. Setup environment
cat > .env.local << EOF
BINANCE_API_KEY=your_api_key_here
BINANCE_API_SECRET=your_secret_here
USE_OPENCLAW=true
WORKER_INTERVAL_MINUTES=15
ALLOCATION_PERCENT=70
STABLE_PERCENT=30
RISK_PROFILE=balanced
EOF

# 2. Install
npm install

# 3. Terminal 1: Dashboard
npm run dev

# 4. Terminal 2: Fund Manager
npm run worker

# 5. Akses http://localhost:3000
```
